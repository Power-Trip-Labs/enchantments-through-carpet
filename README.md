# Enchantments through Carpet

Hello! This is a very light datapack that allows enchantment power to be transmitted through blocks such as carpet, snow etc.! It allows you to get Level 30 enchantments **with carpets**!

## List of supported blocks

- Carpets
- Amethyst Buds
- Candles
- Lanterns
- Torches
- Slabs
- Stairs
- Signs (on walls)
- All variants of glass and glass panes, except tinted glass.
- Snow

If there is any block you feel should be added or removed from this list, feel free to make an issue in my GitHub! I don't use it often, so I am sorry if I respond late to your issue.
